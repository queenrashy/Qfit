Qfit is a PHP-based fitness web application that provides users with daily fitness facts and motivational quotes. Users can sign up, log in, create posts, like others' posts, and manage their profiles.
  Features
- Daily Fitness Facts & Motivational Quotes
- User Registration & Login
- User Profile Page
- Post Creation
- Like Functionality
- Password Reset & Management

 Technologies Used
-Frontend: HTML, CSS
-Backend: PHP
-Database: MySQL

 Usage
-Sign up or log in
-View a new fitness fact and quote daily
-Visit your profile to update personal info
-Share your fitness progress through posts
-Like posts from other users
